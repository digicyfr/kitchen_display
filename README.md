# Kitchen Display Pro

Professional Kitchen Display System for Restaurants & Food Service - Odoo 17.0 Module

## Installation

1. Download from [Odoo Apps Store](https://apps.odoo.com/)
2. Place the `kitchen_display` folder in your Odoo addons directory
3. Update apps list and install

## Compatibility

- Odoo 17.0 (Community and Enterprise)
